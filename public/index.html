// 주요 기능

분석과 재단을 위한
고성능 시스템

치사 봇은 단순한 음악 재생을 넘어, AI 기반 디스코드 제어가 가능한 비서입니다.

음악 스트리밍

Lavalink 엔진을 사용하여 지연 없는 고음질 음악을 제공합니다. Youtube, SoundCloud 등 다양한 소스를 완벽하게 해석합니다.

대화 맥락 인식

디스코드 내의 최근 대화 흐름을 분석하여 자연스러운 대화를 이어나갑니다. '치사,' 또는 '치사야'라고 부르면 응답합니다.

Agent 시스템

복잡한 요청을 간단한 대화만으로 지시할 수 있습니다.(예: '치사야 노래 10곡 틀어줘.') 지시 가능한 요청은 아래의 SKILLS 목록을 참고해주세요.

음악 추천 엔진

최근 재생한 히스토리를 분석하여, 최적의 추천 목록을 제공합니다.

전용 대시보드 페이지

현재 서버의 재생 곡, queue 목록, 인기 곡 등을 더욱 편리하게 확인 및 제어하기 위한 대시보드 페이지를 지원합니다.

인터랙티브 UI 제어

버튼, 선택 메뉴, 임베드 메시지를 통한 직관적인 조작을 지원합니다. 대기열 편집부터 재생 목록 관리까지 마우스 클릭만으로 가능합니다.

// 명령어

시스템 커맨드

접두사 / 슬래시 명령어를 사용합니다.

음악 재생 & 제어
/play
음악을 재생합니다. (쉼표로 구분 시 여러 곡 재생 가능)
[제목 또는 URL | 비어있는 경우 플레이리스트 재생]
/search
검색 키워드의 상위 5개 결과를 보여줍니다. (버튼으로 재생 가능)
[검색어 또는 URL]
/skip
현재 재생 중인 트랙을 넘기고, 다음 곡으로 넘어갑니다.
—
/stop
모든 재생을 중지하고 연결된 채널에서 퇴장합니다.
—
/queue
대기중인 음악들을 확인/편집할 수 있는 UI를 엽니다.
—
/shuffle
대기열의 곡 순서를 무작위로 섞습니다.
—
/auto
특정 분위기의 노래들로 자동 재생합니다.
[분위기] [활성화 여부]
/loop
반복 재생 모드를 전환합니다. (On / Off)
[활성화 여부]
/pause
현재 노래를 일시정지/재개 합니다.
—
데이터 분석 & 저장
/recommand
히스토리 기반 추천 음악들을 보여줍니다.
[사용자] [개수(1~15)]
/playlist
저장된 플레이리스트 목록을 조회하고 편집 UI를 엽니다.
—
/add
곡을 플레이리스트에 추가합니다.
[제목 또는 URL | 비어있는 경우 현재 재생중인 곡]
/history
서버에서 재생되었던 음악 기록을 보여줍니다.
[사용자]
/clear
자신의 플레이리스트 데이터를 모두 제거합니다.
—
시스템 유틸리티
/echo
치사가 지정한 메시지를 채널에 전송합니다.
[내용]
/dashboard
대시보드에 접근 가능한 링크를 발급 받습니다.
—
// skills

Tactical Profile

치사가 사용할 수 있는 도구 목록들입니다.
'치사야' 또는 '치사,'를 붙여서 메세지를 보내는 경우 필요하다고 판단될 때 알아서 사용합니다.
명령어 사용
치사 봇에 등록된 모든 명령어 사용이 가능합니다.
ex) 노래 틀어줘. 지금 재생 중인 노래 목록 좀 보여줘.
인기 음악 탐색
유튜브 실시간 인기 차트의 목록을 조회합니다.
ex) 요즘 인기있는 노래 틀어줘.
playlist 조회
사용자의 플레이리스트를 조회합니다.
ex) 내 플레이리스트에서 몇 곡 선정해줘.
메세지 읽기
현재 채널의 최근 대화 내역을 조회합니다.
ex) 이 채널에서 욕한 사람 찾아줘.
메세지 고정
특정 메시지를 고정합니다.
ex) ~메세지 찾아서 고정시켜줘.
이모지 반응
특정 메세지에 이모지를 달아줍니다.
ex) ~중에 고민되는데, O, X로 투표해줘.
